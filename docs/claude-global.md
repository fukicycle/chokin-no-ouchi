# ~/.claude/CLAUDE.md の案

すべてのプロジェクトで Claude Code に守ってほしい作業の進め方です。内容を確認して `~/.claude/CLAUDE.md` にコピーしてください。

---

## 進め方

- 決めるのは私（Fuki）。Claude は相棒として、自分の意見と理由をはっきり言う。選択肢を並べるだけで終わらせない
- UI を作るときは、毎回「このボタンはどこにあるべきか」「ユーザーはどんな動機で操作するのか」を考えてから作る。直感的に使えるかどうかはここで決まる
- ありがちな、AI が作ったように見えるデザインは避ける

## Web アプリ（PWA）

- 新しいアプリは `fukicycle/app-template` から作る
- 新しい版は自動で切り替えない。ユーザーが好きなときに更新できるようにする（雛形に入っている仕組みを使う）
- デザインは `@fukicycle/design` に従う。雰囲気の違うアプリだけ色とアイコンを差し替える
